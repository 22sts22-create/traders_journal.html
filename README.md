Trader's Journal

A browser-based trading journal for logging trades, tracking performance over time, and reviewing results with charts and statistics. 

What it is

A self-contained tool that lets a trader record every trade and see how they're actually doing -- weekly, monthly, and yearly -- instead of relying on memory or gut feeling. Built on the principle that you can't improve 
what you can't measure. 

What it does

Trade logging - record trades with the details that matter for review.
P&L tracking - performance broken down by week, month, and year, so both short-term swings and long-term trends are visible.
Charts and stats - visual breakdowns of performance to spot patterns in what's working and what's isn't. 
Import/export - download your logs and load them back in.  
Reminders - set reminders tied to your trading routine.

How it works

Built with HTML, CSS, and JavaScript, running entirely in the browser.  Trade data is entered and stored locally and can be exported to (and re-imported from) a file, keeping the user in control of their own records 
with no account required.

Why I built it

Honest self-review is the difference between improving as a trader and repeating the same mistakes.  Most people don't keep records because the tools are clunky.  This is a clean, no-friction way to log trades and 
actually, look at the numbers - including the ones you'd dismiss.
